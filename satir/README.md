# 薩提爾 四種應對姿態

網址：https://bobayhsu.github.io/fivestory/satir/

## 檔案

| 檔案 | 內容 | 什麼時候改 |
|---|---|---|
| `content.js` | 標題、四種姿態、小說原文、16 組對話、15 個場景、選單 | 改台詞、換場景、改標題 |
| `style.css` | 顏色、字的大小、位置 | 改外觀 |
| `render.js` | 依 `content.js` 自動排出每一頁 | 通常不用動 |
| `nav.js` | 翻頁、點一下出現下一句、選單、左右滑動 | 通常不用動 |
| `img/` | 人物圖、場景照片 | 換圖 |

## 改內容

只改 `content.js`。例如改第 1 組對話的第一句：找到「對話組合」裡第一個 `"台詞"`，改 `{"女": "…"}` 裡的字。

- 對話組合、場景意象的順序：列＝男、欄＝女，依序是 男指責×女指責、男指責×女討好、男指責×女超理智、男指責×女打岔、男討好×女指責……
- 台詞一句一行：`{"女": "…"}`、`{"男": "…"}`、`{"動作": "…"}`

## 注意

改了 `content.js`、`style.css`、`render.js`、`nav.js` 任何一個，要把 `index.html` 裡對應的 `?v=` 數字加 1，不然瀏覽器會讀到舊檔。
